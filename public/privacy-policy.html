3. 위치 및 날씨 기능

날씨 기능을 사용할 때 앱은 기기의 위치 권한을 통해 좌표를 얻습니다. 앱은 좌표를 기상청 격자 좌표(nx, ny)로 변환하고, 기상청 단기예보 API에 격자 좌표와 예보 기준 시각을 요청합니다. 동네 이름 표시는 Android/iOS 운영체제의 네이티브 Geocoder 기능을 사용합니다. 앱은 날씨 캐시를 위해 격자 좌표와 지역명·날씨 결과를 기기에 저장할 수 있습니다.

위치 권한을 허용하지 않으면 현재 위치 기반 날씨·지역 표시가 제한될 수 있습니다.

Supabase — 주 데이터베이스: 운영 프로젝트의 주 리전은 대한민국 서울(ap-northeast-2)입니다. Supabase 안내에 따르면 선택한 리전은 주 데이터베이스와 Auth 데이터 및 Storage 원본·백업의 기본 저장 위치에 적용됩니다. 현재 운영 프로젝트의 Storage bucket은 확인 당시 0개였으므로 Supabase Storage에 이용자 파일을 업로드하는 기능은 사용 중이지 않습니다.

Supabase — 처리자 및 국외 처리: Supabase Data Processing Addendum의 계약 처리자는 Supabase Pte. Ltd.(싱가포르, 65 Chulia Street #38-02/03, OCBC Centre, Singapore 049513)입니다. Supabase는 기술지원·운영을 위해 Supabase Inc.(미국) 및 글로벌 지원 인력이 필요한 경우 제한적으로 데이터에 접근할 수 있다고 안내합니다. 지원 접근은 요청 또는 사고 대응 등 필요한 경우로 제한되고 기록됩니다. 프로젝트 사용량·운영 로그·텔레메트리 등 서비스 운영 정보는 선택한 DB 리전 밖에서 처리될 수 있으며, Supabase는 로그·텔레메트리의 EU 데이터센터 처리·저장을 안내합니다. 이 정보는 주 데이터베이스에 저장되는 앱 업무 데이터와 구분됩니다.

Supabase Edge Functions: 이 앱은 계정 삭제와 Google Forms 양식 분석을 위해 Supabase Edge Functions를 사용합니다. 현재 운영 함수는 delete-account와 analyze-camp-return-form이며 두 함수 모두 JWT 검증이 켜져 있습니다. 앱은 두 함수 호출 시 서울(ap-northeast-2) 리전을 지정합니다. 2026년 11월 25일 운영 로그에서 Google Forms 분석 함수의 실제 실행 리전이 서울로 확인되었습니다. 계정 삭제 함수는 실제 계정 삭제를 발생시키는 테스트를 하지 않아 실행 리전이 아직 별도 검증되지 않았습니다. Supabase는 지정한 리전이 장애를 겪는 경우 다른 리전으로 자동 우회하지 않는다고 안내합니다. 계정 삭제 함수는 Supabase 계정·DB 내 삭제 처리를 수행하고, 양식 분석 함수는 공개 양식 페이지를 일시 분석한 뒤 사용자가 저장한 양식 메타데이터만 서울 리전의 DB에 저장합니다.

Ltd.(싱가포르)가 계약 당사자로 표시되어 있고 제16조는 AdMob 서비스별 약관을 연결합니다. 계약 법인 주소는 Mapletree Business City II, 70 Pasir Panjang Road, #03-71, Singapore 117371입니다. 다만 계약 법인의 소재지가 광고 데이터의 유일한 저장·처리 국가를 의미하지는 않습니다. Google 광고 서비스는 글로벌 데이터센터에서 처리될 수 있으므로 광고 요청 데이터가 싱가포르 외 Google 인프라 또는 관련 법인에서 처리될 수 있습니다. SDK 자동 수집 가능 항목은 IP 주소, 앱 실행·탭·광고 영상 시청 등 앱 상호작용, 진단·성능 정보, 기기·계정 식별자입니다. Google은 광고 서버 로그의 IP 일부를 9개월 후, 쿠키 정보를 18개월 후 익명화한다고 공개하지만 이는 모든 SDK 데이터의 전체 보유기간이 아닙니다.

Google Forms: 양식 분석은 Supabase Edge Function에서 공개 페이지를 읽는 방식으로 수행되며, 저장 버튼을 누르면 링크·고유 ID·캠프명·제목·문항 구조·자동 입력 연결 정보가 Supabase 공용 목록에 저장됩니다. 채번 요청을 열 때에는 운송장/주문번호·기사 아이디·수량·캠프가 포함된 사전 입력 URL을 이용자 기기에서 Google Forms로 엽니다. 양식을 제출하면 응답은 해당 양식 작성자에게 전달됩니다. Google 계정 유형(개인 또는 Workspace), 양식 작성자 및 조직의 데이터 위치·보관 설정에 따라 저장 국가와 보유기간이 달라질 수 있으며, 사용자가 등록한 양식별 작성자·수령자·응답 보관기간은 앱에서 일괄 통제하지 않습니다. 따라서 각 양식 작성자의 개인정보 안내를 확인해야 합니다.

Android/iOS Geocoder: Android 앱은 cordova-plugin-nativegeocoder 3.5.1을 통해 Android Geocoder.getFromLocation을 호출합니다. Android 공식 API와 플러그인 문서는 기기에서 제공하는 Geocoder 백엔드 서비스가 필요할 수 있다고 설명하지만, 제조사·운영체제별 실제 백엔드 제공자와 처리 국가는 앱 코드에서 식별되지 않습니다. iOS 빌드의 플러그인은 Apple Core Location CLGeocoder의 네트워크 역지오코딩 기능을 사용하므로 좌표가 Apple의 지오코딩 서비스로 전송될 수 있습니다. Apple의 해당 처리 국가·보유기간은 현재 확인한 개발자 문서만으로 특정할 수 없습니다. iOS 버전의 실제 배포 여부와 운영 설정도 출시 전에 확인합니다.

Firebase Hosting: 공개 홈페이지·개인정보 처리방침·계정 삭제 안내는 Firebase Hosting으로 제공합니다. Google/Firebase는 Hosting의 악용 방지·이용량 분석을 위해 방문자 IP 주소와 요청 정보를 처리할 수 있고, IP 관련 로그는 수개월 보관될 수 있다고 안내합니다. Firebase Hosting은 특정 국가 리전을 선택하는 방식이 아닌 Google 글로벌 인프라를 사용하므로 데이터가 Google 또는 그 대리인이 시설을 운영하는 국가에서 처리될 수 있습니다. Firebase 계정의 구체적인 계약 법인·서비스 약관은 운영 계정에서 최종 확인합니다.

기상청 공공데이터포털: 앱은 원시 위도·경도를 기상청 요청에 넣지 않고 기기에서 격자 좌표(nx, ny)로 변환하여 기준일시와 함께 대한민국 기상청 API로 직접 요청합니다. 따라서 현재 코드 흐름상 원시 GPS 좌표의 기상청 전송은 확인되지 않았습니다. API 요청에는 이용자의 네트워크 IP와 API 요청 정보가 노출될 수 있습니다.
